# DecodeLabs Project 3 - CI/CD Pipeline

## Description

This project demonstrates the basics of a CI/CD pipeline using GitHub Actions.

## Objective

- Understand Continuous Integration and Continuous Deployment
- Automate build and test steps
- Trigger the pipeline using Git push
- Use GitHub Actions workflows
- Store sensitive credentials using GitHub Secrets
- Prepare automated deployment to an AWS EC2 server

## Application

This project contains a simple HTML application used to demonstrate the CI/CD workflow.

## CI/CD Flow

Git Push → GitHub Actions → Build → Test → Artifact → Deployment

## Technologies

- Git
- GitHub
- GitHub Actions
- YAML
- Linux
- AWS EC2
- SSH
